Class activities

One per class meeting. Ungraded — they exist so that the assignment is not the first time you meet the idea.

Activity 1 — Create the Dangling-Else Conflict, Then Fix It Three Ways

Build the conflict on purpose, read the items in parser.output, fix it with precedence and again with a matched/unmatched grammar, then swap the declarations and watch it break.

Activity 2 — Lower Nested Conditionals

Count the labels, draw the flow graph, execute all four cases, then remove one jump and see which cases still look fine.

Activity 3 — Short-Circuit or Not — Decide It

Both of Dragon's translations, a truth table, the bitwise-and trap, and a measurement.

Activity 4 — switch: Chain, Table, or Binary Search

Lower it by hand with fall-through, then cost all three strategies against four different case distributions.

Activity 5 — Audit Somebody Else's Compiler

Five adversarial programs each, rotate, diagnose by phase, fix one bug before you leave.

Activity 6 — MIPS vs ARM — What Would Actually Change

Hand-translate one function, meet predication and condition flags, then mark every file in your compiler unchanged, edited, or rewritten.
