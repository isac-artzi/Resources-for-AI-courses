Class activities

One per class meeting. Ungraded — they exist so that the assignment is not the first time you meet the idea.

Activity 1 — Lower a Loop, Then Draw Its Flow Graph

Labels and jumps on paper, hand-execute it, find the basic blocks and the back edge, then move the test to the bottom and see what you built.

Activity 2 — for vs while — a Design Decision

Lower directly or desugar? Write both, settle the degenerate cases, and let continue tell you which is riskier.

Activity 3 — break, and the continue You Are Not Implementing

A label stack, a depth counter, and a two-sentence argument for why no grammar could have caught it.

Activity 4 — Optimize a Listing by Hand

Pass by pass to a fixed point, naming every transformation, then break the label rule and meet the worst failure mode in compilers.

Activity 5 — Measure It, and Defend the Number

Code size and work done are different numbers. Get both, repeat the run, and state a threshold you can justify.

Activity 6 — Unrolling, Code Motion, Strength Reduction

Three loop optimizations by hand — two you will not implement, and one you already have without noticing.
