# R-Pi AI Camera Workshop

## ▶ [Open the tutorials](https://isac-artzi.github.io/Resources-for-AI-courses/r-pi-with-ai-camera-workshop/)

An eight-topic hardware workshop built around the Raspberry Pi AI Camera, taking you from a first
capture through on-camera inference and live preview. Each topic pairs a tutorial with exercises.

The tutorial files in `tutorials/` are HTML. **Use the link above** — github.com displays `.html`
files as source code, so clicking one in the file browser shows markup instead of the page.

## Project templates

Seven starter projects in [`Project Templates/`](./Project%20Templates), one per stage of the
workshop: Cam_1_hello-capture, Cam_2_stream-fps, Cam_3_control-sweep, Cam_4_ai-inference, Cam_5_frame-to-numpy, Cam_6_clip-record-playback, and Cam_7_live-preview.
