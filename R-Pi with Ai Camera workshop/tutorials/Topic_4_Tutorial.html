Topic 4 · Image Segmentation and Edge Detection

Topic 4 covers finding boundaries (edge detection) and dividing an image into meaningful regions (segmentation). Both run cleanly in real time on the IMX500's captured or live frames — no workarounds needed here.

Scope: Sobel, Canny, and Laplacian edge detection; Otsu's thresholding for segmentation; comparing accuracy vs. computational cost across methods.

1. Sobel, Canny, and Laplacian — three ways to find an edge

MethodHow it worksCharacter
SobelFirst-derivative gradient in x and yDirectional, noise-sensitive, fast
CannyGradient + non-max suppression + hysteresis thresholdingThin, clean, connected edges; the usual default
LaplacianSecond-derivative (zero-crossing)Very noise-sensitive; often pre-blurred first
 
sobel_x = cv2.Sobel(gray, cv2.CV_64F, 1, 0, ksize=3)
sobel_y = cv2.Sobel(gray, cv2.CV_64F, 0, 1, ksize=3)
canny   = cv2.Canny(gray, threshold1=100, threshold2=200)
laplac  = cv2.Laplacian(gray, cv2.CV_64F)

2. Canny's two thresholds actually matter

Canny classifies gradient pixels as strong (above threshold2), weak (between the two thresholds), or discarded (below threshold1) — weak pixels only survive if they connect to a strong one. Set the thresholds too tight and you lose real edges; too loose and you get noise. There is no universal value — tune against your own captures.

3. Otsu's thresholding: picking the cutoff automatically

Otsu's method finds the intensity threshold that best separates a bimodal histogram into foreground and background — it minimizes the combined variance within each resulting class. It works well when the histogram genuinely has two peaks (e.g. a clearly lit object against a plain background); it degrades on flat or evenly lit scenes. 

_, otsu = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)

4. Accuracy vs. computational cost

Sobel and Laplacian are single-pass convolutions — cheap, but noisy without pre-filtering. Canny does more work (gradient, suppression, double-threshold hysteresis) for noticeably cleaner output. On a Pi 5 this difference is measurable but not painful for stills; for live video, the cost adds up per frame and is worth timing.
