Topic 1 · Introduction to Digital Image Processing

Topic 1 is your introduction to what a digital photo actually is: a grid of numbers. By the end of this tutorial you will understand how the AI Camera turns light into a NumPy array, how to read that array's shape and dtype, and how resize, crop, and grayscale conversion are all just different ways of reindexing or collapsing that array.

Scope: pixels, arrays, color channels, resizing, cropping, grayscale conversion, and histograms. This is foundational — every later topic builds on treating an image as data.

1. A photo is a NumPy array

When picamera2 captures a still from the IMX500, it hands you back a NumPy array shaped (height, width, channels) — typically (1080, 1920, 3) at full resolution, one byte per channel per pixel (dtype=uint8, values 0–255). There is no "image object" underneath; everything downstream — filtering, edge detection, compression — is array math. 

from picamera2 import Picamera2
picam2 = Picamera2()
picam2.start()
frame = picam2.capture_array()   # numpy.ndarray, shape (H, W, 3)
print(frame.shape, frame.dtype)

2. Color channel order — the classic "blue image" bug

picamera2 delivers frames in BGR order by default, but matplotlib and most image-saving code expect RGB. Display a raw capture with plt.imshow() without converting first, and skin tones turn blue and skies turn orange. Fix it with a single channel swap before display or save: 

import cv2
rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
Watch for this: if your colors look inverted in every screenshot, this is almost always the cause. It's documented in the Cam 5 (Frame to NumPy) project template for exactly this reason.

3. Resize, crop, and grayscale are array operations

Resizing to half size resamples the pixel grid — cv2.resize() interpolates new pixel values from neighboring originals; it does not simply delete rows. Cropping the central 50% is plain NumPy slicing — no interpolation, just selecting a sub-array. Grayscale conversion collapses the 3-channel array to 1 channel via a weighted sum (0.299R + 0.587G + 0.114B), not a simple average — this weighting matches human luminance perception. 

h, w = frame.shape[:2]
resized  = cv2.resize(frame, (w // 2, h // 2))
cropped  = frame[h//4 : 3*h//4, w//4 : 3*w//4]           # central 50%
gray     = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)

4. Histograms show what the numbers mean

A histogram counts how many pixels fall at each intensity value (0–255). A histogram bunched near 0 means a dark, underexposed image; bunched near 255 means blown-out highlights; a wide, even spread means good tonal range. Compare the original color image's per-channel histogram against the grayscale histogram — the grayscale one is a single curve where the color one is three overlaid curves.
