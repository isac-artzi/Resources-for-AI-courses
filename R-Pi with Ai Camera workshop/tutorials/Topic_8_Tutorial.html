Topic 8 · Image and Video Compression

Topic 8 covers the Discrete Cosine Transform (DCT) compression pipeline that underlies JPEG and most video codecs, plus a discussion hook into AI-driven compression that the IMX500's on-chip inference makes directly relevant.

Scope: DCT, quantization, reconstruction via inverse DCT, and PSNR-based quality evaluation. A conceptual look at AI-based real-time compression closes the topic.

1. The compression pipeline in three steps

StepWhat it does
DCTConverts the spatial image into the frequency domain — most natural-image energy concentrates in a few low-frequency coefficients
QuantizationDivides coefficients by a step size and rounds — this is the lossy step, discarding high-frequency detail the eye is least sensitive to
ReconstructionInverse DCT rebuilds an approximate image from the quantized coefficients

2. DCT and quantization in code

import numpy as np, cv2

block = gray[0:8, 0:8].astype(np.float32)
dct_block = cv2.dct(block)

quant_matrix = np.ones((8,8)) * 10        # simple uniform quantization step
quantized = np.round(dct_block / quant_matrix)

reconstructed = cv2.idct(quantized * quant_matrix)

Real JPEG uses an 8×8 block DCT across the whole image with a standard (non-uniform) quantization table that keeps more precision in low frequencies — this simplified version demonstrates the same principle on one block at a time.

3. The size/quality trade-off is the whole point

Larger quantization steps mean smaller file sizes but more visible blocking artifacts and quality loss — that is the entire compression trade-off. Sweep the quantization step across a few values, measure both resulting file size and PSNR, and plot the trade-off curve. A single number in isolation ("PSNR = 32 dB") means far less than the curve showing where quality falls off a cliff.

4. AI in compression — a discussion hook, not a required implementation

The IMX500's headline feature is on-sensor AI inference — it runs a neural network directly on the sensor chip, producing detection or classification results without sending full frames to the CPU. This is directly relevant to the AI-driven-compression discussion question: modern approaches increasingly decide what to encode based on learned importance (e.g. keep faces sharp, compress background harder) rather than applying a uniform quantization table everywhere. No graded topic in this course requires implementing this — it's conceptual grounding for the discussion questions.
