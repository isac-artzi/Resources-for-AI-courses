# Gymnasium IS a serving dependency in this course, and it is worth being
# precise about why that does not contradict the no-framework rule.
#
# `POST /rollout` runs bounded evaluation episodes server-side — that is a
# standing endpoint, not an extra — so the deployed process has to be able to
# construct the environment. Gymnasium is pure Python over NumPy: about 3 MB
# installed, ~15 ms to import, no compiled extension, no bundled CUDA
# libraries. The rule this course enforces is not "few dependencies"; it is
# "the artifact you deploy is not the training graph." A 3 MB environment API
# is not a training graph. A 490 MB tensor library with a CUDA runtime is.
#
# The classic-control extra only, never gymnasium[all]: `all` still declares
# the obsolete swig-dependent Box2D package and fails to install.
gymnasium[classic-control]==1.0.0
