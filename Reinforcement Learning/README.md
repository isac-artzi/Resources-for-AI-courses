# Reinforcement Learning

## ▶ [Open the tutorials](https://isac-artzi.github.io/Resources-for-AI-courses/reinforcement-learning/)

Six topics from the basics through policy gradients, actor-critic, tree search and RLHF, each with a tutorial and exercises. Agent templates live in `Project templates/`.

The tutorial files in this folder are HTML. **Use the link above** — github.com displays `.html` files as source code, so clicking one in the file browser shows markup instead of the page.

## In this folder

- [`Tutorials/`](./Tutorials) — the tutorial and exercise pages (source files)
