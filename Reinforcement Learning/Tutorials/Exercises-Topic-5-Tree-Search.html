Computational · Exhaustive node count

Question 1

A game tree has branching factor b = 3 and depth d = 5. Exhaustive minimax visits every node, including the root. How many nodes does it visit in total?
Hint · Level k holds bk nodes, and the levels run from k = 0 to k = d. The geometric sum is (bd+1 − 1)/(b − 1).

Question 2

Same tree: b = 3, d = 5. A heuristic search visits only 30% of the nodes at each level below the root, and always expands the root itself. How many nodes does it visit in total? Give one decimal place.
Hint · The root is one node. Below it, levels 1 through 5 hold 3 + 9 + 27 + 81 + 243 nodes, and the search touches 30% of that.
Computational · The α–β best case

Question 3

A search has branching factor b = 9 and searches to depth d = 6. Under perfect move ordering, α–β pruning examines approximately bd/2 leaves. How many leaves is that?
Hint · The effective branching factor falls to √b, so the leaf count is (√9)6 = 93. Compare it with the unpruned 96.
Computational · A UCT value by hand

Question 4

A child node in an MCTS tree has Wi = 7 accumulated wins over Ni = 20 visits. Its parent has been visited N = 400 times and the exploration constant is C = √2. Compute the child's UCT value to three decimal places.
Hint · UCT = Wi/Ni + C·√(ln N / Ni). Note that the logarithm is natural, not base 10: ln 400 ≈ 5.9915.
